# SyncSpace

### Interactive Digital Therapy Platform

SyncSpace is a modern digital therapy platform designed to make remote therapy sessions more engaging, interactive, and accessible.

It combines secure video-session concepts with collaborative therapeutic activities that therapists can use during online sessions.

## 🌐 Live Demo

https://syncspace-q2yb-9k7n40wwc-mshanshika.vercel.app

## ✨ Features

- 🎥 Interactive therapy session interface
- 🧩 Collaborative therapy activities
- 🧠 Playable Memory Match module
- 🫧 Bubble Splash activity preview
- 🧮 Talking Calculator activity preview
- 🌀 Maze activity preview
- 📅 Demo and session booking modal
- 👩‍⚕️ Designed for psychologists and counselors
- ♿ Accessibility-focused interface
- 📱 Responsive design for desktop and mobile
- ⚡ Smooth animations and micro-interactions
- 🔒 Secure-session capability concept
- 📝 Live clinical notes capability concept
- 📆 Smart session scheduling capability

## 👥 Who It's For

SyncSpace is designed for therapists and counselors supporting users with different needs, including:

- ADHD
- Specific Learning Disabilities
- Anxiety
- Depression
- Intellectual Disabilities
